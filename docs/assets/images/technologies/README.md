# Icones de tecnologias

Cada icone deve ter o mesmo slug usado em `js/data.js`:

```js
{ name: "React", icon: "react" }
```

Nesse caso, o arquivo esperado e `react.svg` nesta pasta.

## Adicionar uma tecnologia

1. Copie `technology-template.svg` ou coloque aqui o SVG oficial da tecnologia.
2. Renomeie o arquivo para o slug usado no `data.js`, por exemplo `kotlin.svg`.
3. Adicione a tecnologia em `js/data.js` usando `icon: "kotlin"`.

Nao e necessario alterar `js/modules/icons.js`.
